# gaugeepoch

Gauge HTML/Markdown epoch fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/gaugeepoch/

## Install / run

```bash
git clone https://github.com/theworker02/gaugeepoch.git
cd gaugeepoch
node src/cli.js
node --test
```
